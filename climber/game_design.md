We would like to make a simple web based game.

Our game should be based inside of a climbing gym, like Hapik (in Industry City).  
The game should have multiple levels.  Each level should be continuous, like 
scrolling to the next climb to the left or right.  In each level, the climber (main
character) should have to climb up the wall, which works as a platform challenge 
the climber has to jump between platforms, climb ladders, hang on bars, and go through 
tubes.  When you get to the top of a climb, there should be an exlosion of confetti.

The climber should be a 4 year old boy, with blond hair, and a colorful necklace.
